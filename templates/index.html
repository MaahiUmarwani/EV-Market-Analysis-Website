About the Project

How it was built

Approach

  1. Data: connected the EV market dataset (ev_market_train.csv) in Tableau.
  2. Preparation: checked field types and converted the data source to an extract for Tableau Public.
  3. Analysis: built 9 worksheets: KPI summary, sales trend, category, country, region, manufacturers, battery share, range and a rating heatmap.
  4. Dashboard: combined the views with global filters and a battery-type filter action, at a fixed 1200 px layout.
  5. Story: created a Tableau Story to present the findings step by step.
  6. Publishing: published to Tableau Public and embedded in this Flask website.
  7. Website: built with Python, Flask, HTML and CSS, and deployed on Render.
